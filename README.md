# CS225 Data Structures Coursework

A personal archive of coursework for CS225: Data Structures at the University of Illinois Urbana-Champaign, Spring 2026.

## Machine Problems

- **Lists:** Linked-list operations.
- **Mosaics:** KD-trees and nearest-neighbor search for photo mosaics.
- **Traversals:** Image traversal and flood-fill operations.
- **Mazes:** Disjoint sets, maze generation, and pathfinding.
- **Stickers:** Image manipulation and composition.
- **Puzzle:** Puzzle solving and search algorithms.

## Labs

Practice with trees, AVL trees, B-trees, hash tables, heaps, stacks, queues, dictionaries, Huffman coding, network flow, and other data structures and algorithms.
